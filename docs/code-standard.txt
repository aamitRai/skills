## 1. Imports & Module Structure

Group and separate imports in this strict order:

```python
# 1. Built-in modules
import os
import sys
from datetime import datetime
from pathlib import Path

# 2. Third-party modules
import httpx
from fastapi import FastAPI, Depends
from pydantic import BaseModel

# 3. Local application modules
from app.core.config import settings
from app.services.user_service import UserService
from app.repositories.user_repository import UserRepository
```

**Rules:**
- One blank line between each group
- Use **absolute imports** for all projects beyond a single file
- Avoid circular imports at all costs — restructure if needed
- Never use wildcard imports: `from module import *`

---

## 2. Spacing & Layout Rules

- Two blank lines before and after **class** definitions
- One blank line between **methods** inside a class
- Max line length: **88 characters** (Black standard / PEP8)
- Files must end with **one newline**
- No trailing whitespace on any line

---

## 3. Clean Code Practices

### Must Remove Before Any PR
- Unused variables
- Unused imports
- Dead / unreachable functions
- Commented-out code blocks
- `pass` statements left from scaffolding

### Naming Rules

| Target | Convention | Example |
|---|---|---|
| Variables & functions | `snake_case` | `get_user_by_id` |
| Classes | `PascalCase` | `UserService` |
| Constants | `UPPER_CASE` | `MAX_RETRY_COUNT` |
| Private methods | `_snake_case` | `_validate_token` |
| Pydantic models (response) | `PascalCase` | `UserResponse` |
| FastAPI routers | `snake_case` | `user_router` |

## 4. Logging Over Print

**Never use `print()` in production code.**

```python
# BAD
print("User created:", user_id)

# GOOD
import logging

logger = logging.getLogger(__name__)

logger.info("User created successfully", extra={"user_id": user_id})
logger.warning("Rate limit approaching", extra={"user_id": user_id, "count": count})
logger.error("Failed to create user", exc_info=True, extra={"name": name})
```

- Use `__name__` as the logger name in every module
- Always pass structured context via `extra={}`
- See Standard #26 for structured JSON logging configuration

## 5. Return Types & Type Hints

**Every function must have full type annotations — parameters and return type.**

```python
# BAD
def create_user(name, email):
    ...

# GOOD
def create_user(name: str, email: str) -> int:
    ...

# Async
async def get_user(user_id: int) -> UserResponse | None:
    ...

# Collections
def get_active_users(limit: int = 10) -> list[UserResponse]:
    ...

# Optional parameters
def find_user(email: str, active: bool | None = None) -> UserResponse | None:
    ...
```

## 6. Functions & Methods

- **One function = one responsibility** (Single Responsibility Principle)
- **Ideal length:** ≤ 20 lines
- **Hard maximum:** 40 lines — split if exceeded
- Avoid boolean flags that alter behavior; split into two functions instead
- Avoid more than **3–4 parameters** — group into a Pydantic model or dataclass

```python
# BAD — boolean flag smell
def process_user(user_id: int, send_email: bool) -> None:
    ...

# GOOD — explicit, separate functions
def process_user(user_id: int) -> None:
    ...

def process_user_with_notification(user_id: int) -> None:
    process_user(user_id)
    send_welcome_email(user_id)
```

## 7. Error Handling

- **Never** catch bare `Exception` blindly
- Always raise **meaningful custom exceptions**
- **Fail fast** — validate early, surface errors immediately
- Log exceptions with full stack trace at the point of raising

```python
# exceptions/user_exceptions.py
class UserNotFoundError(Exception):
    """Raised when a user cannot be located by the given identifier."""
    pass

class UserAlreadyExistsError(Exception):
    """Raised when attempting to create a duplicate user."""
    pass

class InvalidUserStateError(Exception):
    """Raised when a user operation is invalid given current state."""
    pass

# Usage
async def get_user(user_id: int) -> UserResponse:
    user = await user_repository.find_by_id(user_id)
    if not user:
        logger.warning("User not found", extra={"user_id": user_id})
        raise UserNotFoundError(f"User with ID {user_id} not found")
    return user
```

## 8. Configuration Management

- **Never** hardcode secrets, URLs, or environment-specific values
- Use **environment variables** for all configuration
- Centralize all config access through a single settings object (Pydantic `BaseSettings`)

```python

from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    DATABASE_URL: str
    SECRET_KEY: str
    REDIS_URL: str
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 30
    MAX_CONNECTIONS: int = 10

    class Config:
        env_file = ".env"
        env_file_encoding = "utf-8"

settings = Settings()

# Usage anywhere in the project
from app.core.config import settings
db_url = settings.DATABASE_URL
```

## 10. Database & External Calls

- Always set **explicit timeouts** — never leave them as default/infinite
- Handle **retries** explicitly with backoff
- **Never block the event loop** in async code — use async clients
- Use connection **pooling** with sensible limits

```python
# BAD — blocking call inside async function
async def get_data() -> dict:
    response = requests.get(url)  # BLOCKS event loop

# GOOD — async http client
import httpx

async def get_data(url: str) -> dict:
    async with httpx.AsyncClient(timeout=httpx.Timeout(5.0)) as client:
        response = await client.get(url)
        response.raise_for_status()
        return response.json()

# Database with SQLAlchemy async
async with async_session() as session:
    result = await session.execute(select(User).where(User.id == user_id))
```

## 14. API Versioning (Mandatory)

**Always version your APIs from day one.** Never break existing clients.

```python
# main.py
from fastapi import FastAPI
from app.api.v1 import router as v1_router
from app.api.v2 import router as v2_router

app = FastAPI()
app.include_router(v1_router, prefix="/api/v1")

router = APIRouter(prefix="/users", tags=["users-v1"])

    ...
```

- Deprecate, don't delete — keep old versions alive for a defined sunset period
- Document breaking changes in a `CHANGELOG.md`
- Use `Deprecated` response headers for sunset notice

## 15. Strict Separation of Concerns

**Four-layer architecture is mandatory. No layer skips.**

```
api/v1/users.py         ← Route layer     : HTTP in/out only
services/user_service.py ← Service layer  : Business logic only
repositories/user_repo.py ← Repository layer : DB queries only
models/user.py          ← Model layer     : Schema definitions only
```

```python
# api/v1/users.py — Route layer ONLY handles HTTP
@router.post("/", response_model=UserResponse, status_code=HTTP_201_CREATED)
async def create_user(
    payload: UserCreateRequest,
    service: UserService = Depends(get_user_service),
) -> UserResponse:
    return await service.create(payload)

# services/user_service.py — Business logic ONLY
class UserService:
    def __init__(self, repo: UserRepository) -> None:
        self._repo = repo

    async def create(self, payload: UserCreateRequest) -> UserResponse:
        await self._validate_unique_email(payload.email)
        user = await self._repo.create(payload)
        return UserResponse.model_validate(user)

# repositories/user_repository.py — DB access ONLY
class UserRepository:
    async def create(self, payload: UserCreateRequest) -> User:
        ...
```

## 16. No `Any` Type — Write Proper Types

**`Any` is a type-safety escape hatch and must never appear in production code.**

```python
# BAD
from typing import Any

def process(data: Any) -> Any:
    ...

def get_config() -> dict[str, Any]:
    ...

# GOOD
from pydantic import BaseModel

class ProcessInput(BaseModel):
    user_id: int
    action: str

class ProcessResult(BaseModel):
    success: bool
    message: str

def process(data: ProcessInput) -> ProcessResult:
    ...

# If truly dynamic, use TypedDict or Union
from typing import TypedDict

class ConfigDict(TypedDict):
    host: str
    port: int
    debug: bool
```

## 18. Middleware Usage

Global middlewares must be applied consistently across the application.

```python
# main.py
import uuid
from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
from starlette.middleware.base import BaseHTTPMiddleware

app = FastAPI()

# 1. CORS
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.ALLOWED_ORIGINS,
    allow_methods=["*"],
    allow_headers=["*"],
)

# 2. Request Trace ID (correlation ID for log tracing)
class TraceIDMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        trace_id = request.headers.get("X-Trace-ID", str(uuid.uuid4()))
        request.state.trace_id = trace_id
        response = await call_next(request)
        response.headers["X-Trace-ID"] = trace_id
        return response

# 3. Request logging middleware
class RequestLoggingMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        logger.info("Request started", extra={
            "method": request.method,
            "path": request.url.path,
            "trace_id": getattr(request.state, "trace_id", None),
        })
        response = await call_next(request)
        logger.info("Request completed", extra={"status_code": response.status_code})
        return response

app.add_middleware(TraceIDMiddleware)
app.add_middleware(RequestLoggingMiddleware)
```

## 19. Centralized Exception Handling

Handle all known exceptions in one place. No try/except scattered across route handlers.

```python
# core/exception_handlers.py
from fastapi import Request
from fastapi.responses import JSONResponse
from app.exceptions.user_exceptions import UserNotFoundError, UserAlreadyExistsError
from app.constants.http_status import HTTP_404_NOT_FOUND, HTTP_409_CONFLICT, HTTP_500_INTERNAL_SERVER_ERROR

def register_exception_handlers(app: FastAPI) -> None:

    @app.exception_handler(UserNotFoundError)
    async def user_not_found_handler(request: Request, exc: UserNotFoundError):
        return JSONResponse(
            status_code=HTTP_404_NOT_FOUND,
            content={"error": "user_not_found", "message": str(exc)},
        )

    @app.exception_handler(UserAlreadyExistsError)
    async def user_conflict_handler(request: Request, exc: UserAlreadyExistsError):
        return JSONResponse(
            status_code=HTTP_409_CONFLICT,
            content={"error": "user_already_exists", "message": str(exc)},
        )

    @app.exception_handler(Exception)
    async def unhandled_exception_handler(request: Request, exc: Exception):
        logger.critical("Unhandled exception", exc_info=True)
        return JSONResponse(
            status_code=HTTP_500_INTERNAL_SERVER_ERROR,
            content={"error": "internal_error", "message": "An unexpected error occurred"},
        )

# main.py
register_exception_handlers(app)
```

## 20. Pagination & Filtering (Production Requirement)

**Never return unbounded datasets.** Every list endpoint must be paginated.

```python
# schemas/pagination.py
from pydantic import BaseModel, Field

class PaginationParams(BaseModel):
    skip: int = Field(default=0, ge=0, description="Number of records to skip")
    limit: int = Field(default=20, ge=1, le=100, description="Max records to return")

class PaginatedResponse(BaseModel):
    data: list
    total: int
    skip: int
    limit: int
    has_more: bool

# Usage in route
@router.get("/users", response_model=PaginatedResponse)
async def list_users(
    pagination: PaginationParams = Depends(),
    service: UserService = Depends(get_user_service),
) -> PaginatedResponse:
    return await service.list_users(pagination)
```

## 21. Dependency Injection via FastAPI `Depends()`

**Never instantiate services or repositories inside route handlers manually.**
Use FastAPI's DI system for clean, testable, and mockable code.

```python
# dependencies/user_deps.py
from functools import lru_cache
from app.repositories.user_repository import UserRepository
from app.services.user_service import UserService
from app.core.database import get_async_session

async def get_user_repository(
    session: AsyncSession = Depends(get_async_session),
) -> UserRepository:
    return UserRepository(session)

async def get_user_service(
    repo: UserRepository = Depends(get_user_repository),
) -> UserService:
    return UserService(repo)

# Route — clean, no manual wiring
@router.get("/{user_id}", response_model=UserResponse)
async def get_user(
    user_id: int,
    service: UserService = Depends(get_user_service),
) -> UserResponse:
    return await service.get_by_id(user_id)

# In tests — override easily
app.dependency_overrides[get_user_service] = lambda: MockUserService()
```

## 22. Pydantic Schema Design — Separate Input / Output Models

**Never reuse the same Pydantic model for request, response, and DB model.**
Each model has one purpose.

```python
# schemas/user_schemas.py
from pydantic import BaseModel, EmailStr, Field
from datetime import datetime

class UserCreateRequest(BaseModel):
    """Incoming payload from client to create a user."""
    name: str = Field(..., min_length=2, max_length=100)
    email: EmailStr
    password: str = Field(..., min_length=8)

class UserUpdateRequest(BaseModel):
    """Incoming payload for partial user update."""
    name: str | None = Field(default=None, min_length=2, max_length=100)
    email: EmailStr | None = None

class UserResponse(BaseModel):
    """Outgoing payload returned to the client."""
    id: int
    name: str
    email: str
    created_at: datetime

    model_config = {"from_attributes": True}

class UserInDB(UserResponse):
    """Internal representation including sensitive fields — never expose via API."""
    hashed_password: str
```

## 23. Async Best Practices

Improper async usage silently destroys performance and causes subtle bugs.

```python
# BAD — blocking I/O inside async function
import time
import requests

async def fetch_report() -> dict:
    time.sleep(2)                        # BLOCKS event loop
    return requests.get(url).json()      # BLOCKS event loop

# BAD — running CPU-bound work in async without executor
async def process_image(data: bytes) -> bytes:
    return heavy_cpu_processing(data)    # BLOCKS event loop

# GOOD — async I/O client
async def fetch_report() -> dict:
    async with httpx.AsyncClient(timeout=10.0) as client:
        response = await client.get(url)
        return response.json()

# GOOD — CPU-bound work offloaded to thread pool
import asyncio
from concurrent.futures import ThreadPoolExecutor

executor = ThreadPoolExecutor(max_workers=4)

async def process_image(data: bytes) -> bytes:
    loop = asyncio.get_event_loop()
    return await loop.run_in_executor(executor, heavy_cpu_processing, data)

# GOOD — parallel async calls
user, orders = await asyncio.gather(
    get_user(user_id),
    get_orders(user_id),
)
```

## 24. Testing Standards

**No PR without tests. Aim for ≥ 80% coverage on service and repository layers.**

```python
# tests/unit/services/test_user_service.py
import pytest
from unittest.mock import AsyncMock, MagicMock
from app.services.user_service import UserService
from app.exceptions.user_exceptions import UserNotFoundError

@pytest.fixture
def mock_repo() -> AsyncMock:
    return AsyncMock()

@pytest.fixture
def user_service(mock_repo: AsyncMock) -> UserService:
    return UserService(repo=mock_repo)

@pytest.mark.asyncio
async def test_get_user_raises_when_not_found(
    user_service: UserService, mock_repo: AsyncMock
) -> None:
    mock_repo.find_by_id.return_value = None

    with pytest.raises(UserNotFoundError):
        await user_service.get_by_id(user_id=999)

# tests/integration/api/test_users_api.py
@pytest.mark.asyncio
async def test_create_user_returns_201(client: AsyncClient) -> None:
    response = await client.post("/api/v1/users", json={
```

**Rules:**
- Unit tests: mock all external dependencies
- Integration tests: use a real test database (Docker-based in CI)
- Test naming: `test_{method}_{condition}_{expected_outcome}`
- One assertion focus per test (can have multiple asserts if they verify the same outcome)
- Use `pytest.fixture` for all shared setup

## 25. Security Standards

Security is non-negotiable. Violating any of these is a blocker.

```python
# 1. Never log passwords, tokens, or PII
logger.info("Login attempt", extra={"email": email})  # OK
logger.info("Login", extra={"password": password})    # NEVER

# 2. Validate and sanitize all input
class UserCreateRequest(BaseModel):
    name: str = Field(..., min_length=1, max_length=100, pattern=r"^[a-zA-Z\s]+$")
    email: EmailStr

# 3. Always hash passwords — never store plain text
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

def hash_password(plain: str) -> str:
    return pwd_context.hash(plain)

def verify_password(plain: str, hashed: str) -> bool:
    return pwd_context.verify(plain, hashed)

# 4. Use parameterized queries — never string-format SQL
# BAD
await session.execute(f"SELECT * FROM users WHERE id = {user_id}")

# GOOD (SQLAlchemy ORM or text with bound params)
await session.execute(select(User).where(User.id == user_id))

# 5. Set security headers via middleware
from secure import Secure
secure_headers = Secure()

@app.middleware("http")
async def set_secure_headers(request: Request, call_next):
    response = await call_next(request)
    secure_headers.framework.fastapi(response)
    return response
```

## 26. Structured JSON Logging

In production, logs must be machine-parseable JSON for aggregation (Datadog, ELK, CloudWatch).

```python
# core/logging.py
import logging
import json
from datetime import datetime, timezone

class JSONFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        log_object: dict = {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
            "module": record.module,
            "function": record.funcName,
            "line": record.lineno,
        }
        if hasattr(record, "trace_id"):
            log_object["trace_id"] = record.trace_id
        if record.exc_info:
            log_object["exception"] = self.formatException(record.exc_info)
        # Merge any extra= fields
        for key, value in record.__dict__.items():
            if key not in logging.LogRecord.__dict__ and not key.startswith("_"):
                log_object[key] = value
        return json.dumps(log_object)

def configure_logging() -> None:
    handler = logging.StreamHandler()
    handler.setFormatter(JSONFormatter())
    logging.root.setLevel(logging.INFO)
    logging.root.handlers = [handler]
```

**Output:**
```json
{
  "timestamp": "2025-09-12T10:23:01.123Z",
  "level": "INFO",
  "logger": "app.services.user_service",
  "message": "User created successfully",
  "trace_id": "a3f2c9d1",
  "user_id": 42
}
```

## 28. Background Tasks

Long-running work (emails, reports, webhooks) must **never** be processed in the request cycle.

```python
# For lightweight tasks — FastAPI BackgroundTasks
@router.post("/users", status_code=HTTP_201_CREATED)
async def create_user(
    payload: UserCreateRequest,
    background_tasks: BackgroundTasks,
    service: UserService = Depends(get_user_service),
) -> UserResponse:
    user = await service.create(payload)
    background_tasks.add_task(send_welcome_email, user.email, user.name)
    return user

# For heavy / retryable tasks — Celery or ARQ
# tasks/user_tasks.py
from arq import create_pool

async def send_weekly_report(ctx: dict, user_id: int) -> None:
    """
    ARQ background task — runs in a separate worker process.

    Args:
        ctx: ARQ worker context containing DB/Redis connections.
        user_id: Target user for the report.
    """
    logger.info("Sending weekly report", extra={"user_id": user_id})
    ...
```

**Rules:**
- Tasks must be **idempotent** — safe to retry on failure
- Always define **max_retries** and **retry_delay**
- Log task start, success, and failure explicitly

## 29. Caching Strategy: skip this

Cache at the **right layer** with **explicit TTL and invalidation strategy**.

```python
# core/cache.py
import json
from functools import wraps
from typing import Callable, TypeVar
import redis.asyncio as aioredis
from app.core.config import settings

redis_client = aioredis.from_url(settings.REDIS_URL, decode_responses=True)

CACHE_TTL_SHORT = 60          # 1 minute
CACHE_TTL_MEDIUM = 300        # 5 minutes
CACHE_TTL_LONG = 3600         # 1 hour

# Usage in repository
class UserRepository:
    async def get_by_id(self, user_id: int) -> User | None:
        cache_key = f"user:{user_id}"
        cached = await redis_client.get(cache_key)
        if cached:
            return User(**json.loads(cached))

        user = await self._db_get_by_id(user_id)
        if user:
            await redis_client.setex(cache_key, CACHE_TTL_MEDIUM, user.model_dump_json())
        return user

    async def invalidate_user_cache(self, user_id: int) -> None:
        await redis_client.delete(f"user:{user_id}")
```

**Rules:**
- Always invalidate cache on write operations (create / update / delete)
- Never cache authentication tokens or PII without encryption
- Use namespaced keys: `entity:id:field` (e.g. `user:42:profile`)
- Define TTL for every cached value — no indefinite caching

## 30. Rate Limiting & Throttling

Every public API endpoint must have rate limits to prevent abuse.

```python
# Using slowapi (FastAPI-compatible rate limiter backed by Redis)
from slowapi import Limiter, _rate_limit_exceeded_handler
from slowapi.util import get_remote_address
from slowapi.errors import RateLimitExceeded

limiter = Limiter(key_func=get_remote_address, storage_uri=settings.REDIS_URL)
app.state.limiter = limiter
app.add_exception_handler(RateLimitExceeded, _rate_limit_exceeded_handler)

# Per-endpoint limits
@router.post("/auth/login")
@limiter.limit("10/minute")             # Strict — auth endpoint
async def login(request: Request, payload: LoginRequest) -> TokenResponse:
    ...

@router.get("/users")
@limiter.limit("100/minute")            # Generous — read endpoint
async def list_users(request: Request, ...) -> PaginatedResponse:
    ...

# Per-user limits (authenticated endpoints)
def get_user_id(request: Request) -> str:
    return str(request.state.user_id)  # From JWT middleware

@router.post("/reports/generate")
@limiter.limit("5/hour", key_func=get_user_id)  # Per authenticated user
async def generate_report(request: Request, ...) -> ReportResponse:
    ...
```

**Rules:**
- Auth endpoints: strict limits (5–10 per minute)
- Read endpoints: generous limits (100–500 per minute)
- Write endpoints: moderate limits (20–50 per minute)
- Return `429 Too Many Requests` with `Retry-After` header
- Log rate limit hits for abuse detection
